SHC Stats · simple SVG icons

41 original vector icons. Transparent backgrounds, one stroke weight, no embedded pictures or fonts. Each card shows 16, 20, 24 and 32px. Click its name to open the individual SVG.

Totals: the small plus means acquired/produced over the match. A plain resource icon means current stock. These are review assets; the existing application interface has not been changed.

Scaling: set the icon's width and height from the same font-size property as the adjacent number. SVG currentColor works in this HTML preview; in Slint, explicitly set Image.colorize to the text color.

Image {
    source: @image-url("../assets/stat-icons/gold.svg");
    width: root.overlay_font_size * 1px;
    height: self.width;
    image-fit: contain;
    colorize: #f5f5f5;
}
